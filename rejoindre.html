La page de votre club est prête 🎉

L’équipe Quartier a préparé la page de votre club avec vos photos et vos offres pour les commerçants. Il ne reste qu’à l’activer avec votre propre compte.

Votre code——————
  1. 1
    Installez l’appli Quartier. Pendant l’avant-première, nous vous envoyons le lien d’installation par message dès qu’elle est disponible pour votre téléphone.
  2. 2
    Créez votre compte avec votre adresse e-mail. Personne d’autre que vous ne connaît votre mot de passe.
  3. 3
    Entrez le code ci-dessus (écran « Que cherchez-vous ? » → « Entrez votre code »), puis appuyez sur « Activer la page du club ».
